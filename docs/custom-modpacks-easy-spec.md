# 自作Modパック機能 ― わかりやすい仕様

*（専門用語をなるべく使わない説明版です。詳しい技術版は
`docs/superpowers/specs/2026-08-24-custom-modpacks-design.md` にあります）*

## これは何？

いまのランチャーは、**oogatakun が用意したModパックを選んで遊ぶ**だけです。
この機能を足すと、**遊ぶ人が自分でMinecraftのバージョンやForge/Fabricを選んで、
自分だけのパック（起動構成）を作って遊べる**ようになります。

イメージは、公式ランチャーやPrismの「起動構成／インスタンス」に近いものを、
沼ぽてランチャーの中に用意する感じです。

## どう見える？

Modパックを選ぶ画面に**タブ**が2つ付きます。

```
┌─────────────────────────────┐
│  [ 公式 ]   [ 自作 ]         │   ← タブ
├─────────────────────────────┤
│  公式：oogatakunのパック一覧  │
│  自作：自分で作ったパック一覧  │
│        ＋ 新規作成            │
└─────────────────────────────┘
```

- **「公式」タブ**：今まで通り、oogatakun のパックが並びます。
- **「自作」タブ**：自分で作ったパックが並びます。「＋ 新規作成」から新しく作れます。

## 自分のパックを作る流れ

「＋ 新規作成」を押すと、こんな項目を選ぶだけ：

1. **Minecraftのバージョン**（例: 1.20.1）
2. **ローダー**（なし／Fabric／Forge のどれか）
3. **ローダーのバージョン**（選んだMinecraftに合うものが一覧で出ます）
4. **名前**（自分で分かる名前を付ける）

作ったら一覧に並びます。**PLAYを押すと、必要なものが自動でダウンロード・準備されて起動**します。

## Modはどう入れる？

**アプリ内のMod管理は、実はもう設定画面にあります。**
設定の「Mod」タブで、Modファイルを**ドラッグ＆ドロップで追加**したり、**削除**したり、
**オン／オフ**を切り替えられます（今は公式パック向けに動いています）。

この機能を、**自作パックでもそのまま使えるようにする**のが今回の対応に含まれます。
なので自作パックでも、設定の「Mod」タブから追加・削除・オンオフができます。
もちろん、各パックの「**フォルダを開く**」ボタンからフォルダに直接入れることもできます。

*（CurseForge/Modrinthからの導入は、さらに先の段階です。下の「段階的に作ります」を参照）*

## 最終的にやりたいこと：みんなで同じ構成を使う

将来、作った起動構成を**ID・コード・URLのような短いテキストにして共有**できるようにします。
- 送る側：自分の構成を「コード書き出し」して相手に送る
- 受け取る側：そのコードを**貼り付けるだけ**で、同じ構成が自分のランチャーに入る

これは**リアルタイム同期ではありません**（相手の変更が自動で反映される、ではない）。
あくまで「その時点の構成をコピーして渡す」仕組みです。共有されるのは版やローダーなどの
**構成情報だけ**で、アカウント等の個人情報は含めません。

## 段階的に作ります（一度に全部ではありません）

大きな機能なので、動くところから順番に積み上げます。

| 段階 | できること |
|------|-----------|
| **① 基盤（まず作る）** | 自作タブ＋バージョンを選んでパック作成・起動。**設定のMod管理も自作パックで使えるようにする** |
| ~~② Mod管理~~ | **もう設定画面にあります**（追加/削除/オンオフ）。①で自作パック対応にするだけ |
| ③ 外部から導入 | CurseForge / Modrinth からMODを探して入れる。**公式パックにも自作パックにも入れられる**（今選んでいるパックのmodsフォルダに入る） |
| ④ 共有 | 構成をコード/URLで書き出し・貼り付け（上の「みんなで同じ構成」） |

まずは **①** をしっかり作り、動いたら③→④と足していきます
（②のMod管理は既にあるので、①で自作パック対応にするだけです）。
①の作り方は、後の段階（特に④の共有）を邪魔しないよう、
**構成を小さなデータとして持つ**設計にしておきます。

## 対応範囲と注意

- **Fabric** は Minecraft 1.14 以降。
- **Forge** はインストーラで入る範囲。**とても新しいForgeやNeoForgeは対応できないことがあります**
  （その場合は分かるように表示します）。
- Minecraftのバージョンはリリース版のみですが、**最新のリリースも選べます**（新しい順で表示。
  一覧はその都度取得して最新に追従）。スナップショットは将来対応。
  ※新しいバージョンほどローダーが未対応のことがあります（Fabricが先、Forgeは遅れがち。
  ローダー「なし」＝バニラなら最新でもOK）。
- 作ったパックは**自分のPC内だけ**に保存されます（共有は④の機能）。
- 準備や起動で失敗したときは、先日作った**「ログを出力」ボタン**でエラー内容を保存して
  相談・解析に使えます。

## できること／できないこと（①の時点）

**できる**
- 自作タブでMC＋ローダーのバージョンを選んでパックを作る
- 名前を付けて一覧管理、フォルダを開く、削除する
- PLAYで自動準備して起動する
- 設定の「Mod」タブで、自作パックのMod追加(ドラッグ＆ドロップ)・削除・オンオフ
- フォルダに直接Modを入れて遊ぶ

**まだできない（後の段階で）**
- CurseForge/Modrinth からの導入（③）
- コード/URLでの共有（④）
